Discord Global Status Monitor 3.2.1 - build notes

Python source: discord_server_global_status.py
Linux Python zipapp: dist/linux/DiscordGlobalStatusMonitor.pyz
Optional Linux C ABI: dist/linux/discord_global_status.so

Linux C ABI build environment:
  OS: Linux x86_64
  CPython: 3.13.5
  OpenSSL: 3.5.5
  C compiler: system cc / CFFI embedding backend

The .so links to libpython3.13.so.1.0 and is not a standalone executable.
Rebuild it with build_linux.sh on the destination system if its CPython ABI,
architecture, or system libraries differ.

Windows EXE and DLL:
  Not prebuilt in this Linux environment. Build them on Windows x64 by running
  build_windows.ps1. The script installs PyInstaller and CFFI into a local venv,
  builds the EXE and C ABI DLL, and signs them with SignTool.
  Visual Studio Build Tools (Desktop development with C++) and Windows SDK
  (SignTool) are required for native DLL compilation and Authenticode signing.

Validation:
  14 offline unit tests passed.
  Python compilation passed.
  Python zipapp --version/help passed.
  Linux C ABI library loaded through ctypes and exported version 3.2.1.
  Live Discord/Globalping endpoints were not reachable during this build because
  the build environment had DNS resolution failures; see --doctor on the target.
